# Privacy Policy - fih_bot

1. **Data Collection**: fih_bot only processes command inputs (e.g., `/play`) and temporary channel configuration IDs (`config.json`).
2. **Data Usage**: Stored IDs are solely used for bot functionality and restricting commands to designated channels.
3. **Data Sharing**: We do not share, sell, or track personal user data or voice content.
4. **Data Removal**: Removing the bot from your server deletes stored configurations.
